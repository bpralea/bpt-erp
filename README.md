# BPT-Moulds Manufacturing · ERP

Aplicație de management pentru atelier de producție CNC.

## Module
- Dashboard cu KPI-uri live
- Comenzi cu flux de lucru (Kanban 7 etape)
- Gestiune clienți (RO/DE/AT/NL/BE/DK)
- Catalog produse & servicii CNC
- Facturi cu export PDF
- Auto-salvare localStorage + Backup/Import JSON

## Rulare locală

```bash
npm install
npm run dev
```

Deschide http://localhost:5173
